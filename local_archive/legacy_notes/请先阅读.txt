IJCAI 2023 论文 DeLELSTM 的三个数据集 × 五个模型，共15组训练和测试已完成。
每组只运行一次，seed=555；尚未完成论文的五次重复实验和解释性图形复现。

三、关键结果（测试RMSE）
Electricity：DeLELSTM 1.673888；论文均值1.7247。
PM2.5：DeLELSTM 27.191918；论文均值26.612。
Exchange：DeLELSTM 0.00234277；论文均值0.0023。
DeLELSTM在本次Electricity和Exchange实验中优于四个基线；PM2.5中RETAIN最佳。
单次结果不能据此认定统计显著优于论文。

四、环境与运行方法（PowerShell）
本次正式GPU实验：Python 3.13，PyTorch 2.14.1+cu126，RTX 3070 Ti Laptop GPU。
不随包提供虚拟环境。请在自己的独立环境中安装依赖，不要修改其他项目共用环境。
依赖快照只记录本次版本，不保证其他Python、系统或硬件下可直接安装。
CUDA版torch需使用匹配的PyTorch官方安装源；可按本次配置先安装：
python -m pip install torch==2.14.1 --index-url https://download.pytorch.org/whl/cu126
python -m pip install -r environment/requirements-gpu.txt
python -c "import torch; print(torch.__version__); print(torch.cuda.is_available())"

进入解压目录的repro/DeLELSTM-main，然后运行：
python Electricity.py --num_exp 1 --save_dirs ../rerun_results
python PM.py --num_exp 1 --save_dirs ../rerun_results
python Exchange.py --num_exp 1 --save_dirs ../rerun_results
这会依次训练各数据集的五个模型。请根据设备资源安排运行，不必同时启动。
使用新输出目录rerun_results，避免覆盖交付结果。
只跑核心模型可先设置：$env:DELE_MODELS='Delelstm'
轮数可通过DELE_EPOCHS覆盖；不设置时Electricity=350，PM和Exchange=300。
作者README中的--model_name不适用于这里的repro入口，以上命令优先。
重新汇总既有结果：进入repro目录后运行 python summarize.py。

这些原始设置存在数据泄漏或评估样本不完整的局限，未当作改进方案。

CPU与GPU结果差异不能仅归因于硬件；未做控制版本和初始化的严格对照。
不能据此断言“CPU无法复现”或“GPU数值路径才正确”。
关于可解释性优化、平滑正则、预测贡献分解，目前属于待验证研究想法，未计入正式结果。

5. summarize.py 现在按 数据集×模型 聚合输出 mean±std；明细另存 summary_detail.csv；

   要得到 mean±std 必须自己跑：见 repro/README_改动说明.md 的“怎么跑”一节。
